## Vision

ObjectSpace is the native object runtime of Sorabbyngo OS.

Traditional operating systems revolve around applications and files.

ObjectSpace revolves around intelligent digital objects.

Users no longer think about applications.

They interact with AION using natural language, gestures, and intent.

ObjectSpace converts those intents into executable object workflows while preserving compatibility with the Linux filesystem for legacy software.
