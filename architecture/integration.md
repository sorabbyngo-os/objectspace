# ObjectSpace Ecosystem Integration

## Overview

ObjectSpace is the universal interaction and object management layer of the Sorabbyngo ecosystem.

It provides

• Intelligent Objects
• Context-aware Workspaces
• Spatial Computing
• Intent-driven Interaction
• AI-native Experiences

ObjectSpace is not an operating system.

ObjectSpace is not a desktop environment.

ObjectSpace is the intelligence layer through which users interact with every subsystem.
